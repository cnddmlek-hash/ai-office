# 내 AI 오피스 (AI Office)

카톡 주문 쪽지·수금 표·보낼 문자 상황을 그대로 붙여넣으면, 픽셀 사무실의 **AI 직원 4명**이
표로 정리해 주는 웹 앱입니다. 설치 없이 브라우저에서 열리고, 홈 화면에 추가하면 폰 앱처럼 뜹니다.

- 라이브: <https://cnddmlek-hash.github.io/ai-office/>
- 안드로이드 크롬에서 위 주소를 연 뒤 **⋮ → 홈 화면에 추가** 를 누르면 앱처럼 실행됩니다.
  (아이폰 사파리는 **공유 → 홈 화면에 추가**)

## 무엇을 해 주나

| 직원 | 역할 | 맡기는 일 |
|---|---|---|
| 충의 | 팀장 | 요청을 읽고 알맞은 직원에게 자동 배정, 결과 검토 |
| 상준 | 주문·반품 정리 | 카톡 주문·반품 메모 → 거래처/품목/규격/수량/특이사항 표 |
| 아름 | 수금·정산 체크 | 회전일·미수잔고·정산서 대조, 연락 우선순위 Top 3 |
| 다영 | 거래처 소통 | 수금 안내·품절·입고 지연 등 카톡/메일 초안 |
| 재희 | 홍보·영상 기획 | 제품 홍보 문구, 원내 안내문, 30초 릴스 대본 |

- 요청을 넣으면 충의 팀장이 직원 책상으로 걸어가 일을 주고, 직원이 끝나면 팀장 자리로 와서 보고합니다.
- 결과는 마크다운 표로 나오고 **[📋 결과 복사]** 로 카톡·엑셀에 바로 붙여넣을 수 있습니다.
- 칸반(할 일 → 하는 중 → 검토 → 완료), 업무 로그, 결과 기록은 브라우저에 자동 저장되며
  **[💾 백업]** / **[📂 불러오기]** 로 파일로 주고받을 수 있습니다.

## API 키 (무료)

진짜 AI가 일하게 하려면 구글 **Gemini API 키**가 필요합니다.

1. <https://aistudio.google.com/apikey> 에서 무료 키를 만듭니다. (`AIza…` 또는 `AQ.…` 형식)
2. 앱 상단 **[🔑 API 키 설정]** 에 붙여넣고 **저장** → **[🔌 연결 테스트]** 로 확인합니다.
3. 키가 없어도 **[🎭 체험 모드]** 로 화면과 흐름을 구경할 수 있습니다(미리 만든 예시 답변).

- 기본 모델은 `gemini-3.8-flash`(무료 등급)이고, 설정에서 다른 모델로 바꿀 수 있습니다.
- 무료 등급은 분당·일일 한도가 있어 **429(한도 초과)**, **402(선불 크레딧 0원)** 같은 안내가 한국어로 뜹니다.
- 키는 **이 브라우저의 localStorage에만** 저장되고 `generativelanguage.googleapis.com` 으로만 전송됩니다.
  서버로 보내지 않으며, 공용 기기에서는 **[키 삭제]** 를 눌러 주세요.

## PWA 구성

| 파일 | 역할 |
|---|---|
| `index.html` | 앱 전체가 들어 있는 단일 실행 파일(HTML+CSS+JS, 외부 라이브러리 없음) |
| `manifest.json` | 앱 이름·아이콘·standalone 실행·테마 색 |
| `sw.js` | 정적 파일만 network-first 캐시. 외부 API 요청은 가로채지 않음 |
| `icon-*.png` | 16×16 픽셀 아트를 확대해 만든 앱 아이콘(any / maskable) |

## 소스 고치고 다시 빌드하기

```sh
python3 build.py                 # src/ → index.html 조립
python3 tools/generate_icons.py  # 아이콘 PNG 다시 만들기
```

- `src/index.html` : 화면 구조·CSS (조립 표시 `<script>/*__ART_JS__*/</script>`, `<script>/*__APP_JS__*/</script>`)
- `src/office-art.js` : 픽셀 사무실 배경·캐릭터 드로잉
- `src/app.js` : 직원 지침, Gemini 호출, 자동 배정, 칸반·로그·저장

빌드 결과는 항상 저장소 루트의 `index.html` 하나이므로, 고친 뒤 `index.html` 을 커밋하면
GitHub Pages에 그대로 반영됩니다.

## 안내

- 화면에 나오는 회사·거래처·품목·사람 이름은 **모두 가상의 예시**입니다(한빛제약 영업1팀, 푸른내과의원, 에이원주 등).
- 실제 업무 자료를 다룰 때는 결과를 그대로 믿지 말고 숫자·날짜를 한 번 확인하세요.
  의학·약학적 효능 표현은 지어내지 않도록 지침에 넣어 두었습니다.
