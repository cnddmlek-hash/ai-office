🕒 사무실 업무 로그

    🔑 Gemini API 키 설정

    무료 키 하나만 넣으면 사무실 직원들이 진짜 Gemini AI로 일합니다. 1분이면 끝나요.

    1. 1
      아래 버튼을 눌러 Google AI Studio를 엽니다.
      구글 계정으로 로그인되어 있으면 바로 열려요.
    2. 2
      파란 Create API key 버튼을 누르고 키를 복사합니다.
      "API 키 만들기"라고 나와도 같은 버튼이에요.
    3. 3
      아래 칸에 붙여넣고 [저장]을 누릅니다.
      키는 이 브라우저에만 저장되고 다른 곳으로 보내지 않아요.
    🔗 Google AI Studio 열기 (무료 키 발급)

    기본은 무료로 쓸 수 있는 Gemini 3.6 Flash예요. 이 모델이 혼잡하면 다른 무료 모델로 자동으로 이어서 처리합니다.

    체험 모드는 미리 만든 예시 답변으로 사무실을 구경하는 모드예요. 내 자료로 진짜 결과를 받으려면 무료 키가 필요합니다.

    🔒 안전 안내 — 키는 이 컴퓨터의 브라우저 저장소(localStorage)에만 보관되고, 구글 Gemini API 주소로만 전송됩니다. 공용 컴퓨터에서는 쓰고 나서 [키 삭제]를 눌러 주세요.

    ❓ 이렇게 쓰면 돼요

    1. 일 맡기기 — 오른쪽 입력창에 카톡 주문·수금 표·보낼 문자 상황을 그대로 붙여넣고 [🚀 일 시키기]를 누릅니다.
    2. 담당자 — 자동 배정을 고르면 팀장 충의가 내용을 읽고 알맞은 직원에게 넘깁니다. 직접 고를 수도 있어요.
    3. 사무실 구경 — 충의 팀장이 직원 책상으로 걸어가 일을 주고, 직원이 일을 마치면 충의 자리로 가서 보고합니다. 오른쪽 업무 결과에 정리된 표가 나옵니다.
    4. 결과 복사 — [📋 결과 복사]를 누르면 표 그대로 카톡이나 엑셀에 붙여넣을 수 있어요.
    5. 자동 저장 — 칸반 카드·결과·로그는 이 브라우저에 자동 저장돼서, 창을 닫았다 열어도 그대로 남아 있어요. [💾 백업]으로 파일로도 받아 둘 수 있습니다.
    🎭 체험 모드는 API 키 없이 화면과 흐름을 구경하는 모드예요. 결과에 [데모 예시] 표시가 붙습니다. 진짜 AI가 일하게 하려면 상단 [🔑 API 키 설정]에서 무료 키를 넣어 주세요.
    💡 무료 한도 — 무료 키는 1분·하루 사용량 한도가 있어요. 한도를 넘으면 직원이 잠시 쉬었다가 다시 하면 됩니다. 급할 땐 모델을 Flash-Lite로 바꾸면 더 여유롭게 쓸 수 있어요.
